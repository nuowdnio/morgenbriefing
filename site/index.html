Damit die Seite das Briefing bei GitHub starten darf, braucht sie einmalig einen Zugangsschlüssel (Token). Er bleibt nur in diesem Browser gespeichert.

  1. Token bei GitHub anlegen (öffnet GitHub).
  2. Name z. B. „Morgenbriefing“, Ablauf nach Wunsch.
  3. Bei Repository access: Only select repositories und dieses Repository wählen.
  4. Bei Permissions: Actions auf Read and write stellen. Sonst nichts.
  5. Auf Generate token tippen, den Token kopieren und hier einfügen.

Texte aus fremdsprachigen Quellen sind maschinell übersetzt und können Fehler enthalten. Maßgeblich sind die verlinkten Originale.
